# SRE course

A hands-on path from backend engineer to SRE. You build one small service,
[`geoquiz-scores`](../../server/) (the GeoQuiz leaderboard API), and operate it like
production. Each week adds a layer, then you break it on purpose and fix it.

| Week | Topic | Guide |
|---|---|---|
| 1 | Linux: processes, `/proc`, signals, systemd, resources | [week-01.md](week-01.md) |
| 2 | Networking: DNS, TCP, TLS, HTTP, nginx load balancing | coming next |
| 3 | Containers: Docker, compose, Postgres + Redis | |
| 4 | Observability: Prometheus, Grafana, Loki, OpenTelemetry | |
| 5 | SLOs, error budgets and burn-rate alerting | |
| 6 | Load testing and capacity (k6, profiling) | |
| 7 | Kubernetes (kind): probes, limits, HPA, rollouts | |
| 8 | Infrastructure as code and CI/CD (Terraform, Actions, Argo CD) | |
| 9 | Reliability patterns and chaos (timeouts, retries, Toxiproxy, backups) | |
| 10 | Incident response: runbooks, game days, postmortems | |
| 11 | Capstone: run it on a real server for two weeks | |
| 12 | Portfolio and interview prep | |
