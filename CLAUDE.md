# Notes for Claude

## Workflow preferences
- Whenever the owner (amrutha-b-nair) asks for a change to this repository, push it and **open a pull request** without waiting to be asked. This applies to repositories the owner personally owns; for repositories owned by others, ask before opening one.
- The owner usually squash-merges PRs. Before starting new work, check whether the previous PR was merged and bring `main` into the working branch first.

## Project
- The app is a static site in `web/` (plain HTML/CSS/JS, no build step), deployed to GitHub Pages by `.github/workflows/pages.yml` after CI passes.
- `web/data/` and `web/img/` are generated by `python3 tools/build_web_data.py` (needs `pip install -r tools/requirements.txt`). Commit the regenerated files; CI fails if they are stale.
- Tests: `npm run test:unit` (answer matching) and `npm run test:e2e` (Playwright, phone and desktop).
- `python/` holds the original Tkinter desktop app and data-prep scripts.
